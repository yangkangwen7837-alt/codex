# 02 · 评分公式与阈值

所有权重/阈值定义在 `configs/default.yaml`，本节说明实现口径。

## LEVEL 1 · Market Regime

```
regime_score = 40% 指数趋势 + 30% 市场宽度 + 15% 成交额 + 15% 涨跌停结构
指数趋势 = 沪深300 站上 MA20(+50) + 站上 MA60(+30) + 60日收益 ±20
市场宽度 = 0.5×MA20 上方占比 + 0.3×20日上涨占比 + 0.2×60日新高占比
```

≥60 → Risk On，≤35 → Risk Off，其余 Neutral。**不删除**任何基本面候选，只输出优先级系数。

## LEVEL 2 · ODS（满分 100）

| 分项 | 权重 | 实现口径 |
|---|---|---|
| 行业基本面趋势 | 30% | 成员公司最新报告期收入同比中位数(35%) + 归母同比中位数(35%) + 利润加速度中位数(30%)，跨行业分位 |
| 行业资金趋势 | 20% | 行业指数 20 日(35%)、60 日(25%) 收益 + 相对沪深300 超额(25%) + 成交额比(15%) 的分位 |
| 盈利预期变化 | 20% | 业绩预告增速中枢中位数(60%) + 预告为正的公司占比(40%)（替代一致预期，账号无权限） |
| 价格/库存周期 | 15% | 行业指数相对 MA60(60%) + 行业存货/收入比变化(40%，取反) |
| 行业估值位置 | 10% | 行业 PE 历史分位取反 |
| 政策/产业催化 | 5% | 近 180 天股东增持与回购事件密度（按行业内成员数标准化） |

≥80 HIGH DENSITY / 70~80 GOOD / 60~70 WATCH / <60 LOW PRIORITY。

## LEVEL 3 · FRS（加分制，满分 100）

**FRS 拆成两部分（2026-10 结构改进，回测驱动）：**

```
结构分（structure）= 100 × Σ加分 / Σ可评估加分      # 方向对不对（规格书第 8~13 节的加分项）
幅度分（magnitude）= 截面分位合成                    # 改善有多大
                  = 30%·分位(Δ收入同比) + 40%·分位(Δ利润同比) + 30%·分位(毛利率同比变化)
FRS = 0.65 × 结构分 + 0.35 × 幅度分                  # 幅度分覆盖率 <50% 时退化为纯结构分
```

为什么要拆：加分制把「收入从 −30% 改善到 −29%」与「从 −5% 改善到 +30%」记成同一个分，
导致"刚触底、改善微弱"的公司被系统性高估。幅度分使用**当日截面的分位数**，保证跨日期可比，
且只使用当日之前可见的数据（无未来函数）。下面的加分项即结构分部分（缺失分项不填充，
覆盖率同时输出）。

| 分项（满分） | 规则（加分） |
|---|---|
| 收入反转（20） | 同比连续两季改善 +5；由负转正 +5；同比增速加速 +5；强于行业中位数 +5 |
| 利润反转（25） | 降幅收窄 +5；由负转正 +5；增速加速且为正 +5；利润增速>收入增速 +5；扣非利润同步改善 +5 |
| 毛利率反转（15） | 触底回升（上季为 4 季最低）+5；连续两季改善 +5；高于过去 4 季均值 +5 |
| 现金流与资产负债表（15） | 经营现金流环比改善且为正 +5；存货占收入比下降 +3；应收增速低于收入 +3；资产负债率同比下降 +2 |
| 经营质量（10） | ROIC 触底 +5；单季 ROE 拐点 +5 |
| 特殊信号（15） | 收入加速且合同负债增长 +5；毛利率同比扩张 >1pct +5；最新业绩预告为正 +5 |
| 扣分项 | CFO/净利为负 −4；应收暴增（>50% 且快于收入）−3；存货暴增（>50%）−3 |

> **低基数不做降级（回测验证结论）**：早先按失败案例库把"低基数"判为最差类别之一，
> 但那是"亏损样本内部的亏损幅度"，属条件概率，不能说明该类别整体更差。
> 改用**无条件均值**比较后：低基数组 60 日净收益 +5.55%（改进前面板）/ +5.36%（改进后面板），
> 均**高于**其余样本（+4.19% / +4.29%）。低基数与"亏损后恢复"高度重合，本就是反转策略要找的对象，
> 因此系统只做披露（标注"低基数需说明"），不降级、不封顶。
> 详见 [07_structural_change_review.md](07_structural_change_review.md)。

### 金融行业专用模板（银行 / 非银金融，2026-10 新增）

银行与保险没有毛利、存货、应收、合同负债，用制造业规则会被判"覆盖率不足"；
更关键的是它们的利润高度受投资收益波动影响（例如中国人寿 2026Q2 单季收入同比 +164%、
归母 +848%，主因是投资类收益计入营业收入），这类波动**不代表经营反转**。

因此 `frs.financial_industries: [银行, 非银金融]` 内的标的改用下列 14 条规则（各 5 分，满分 70，
按可用项归一化到 100，覆盖率上限 0.7 会在输出里如实标注）：

| 分项 | 规则 |
|---|---|
| 收入（10） | TTM 收入同比连续两季改善；TTM 收入同比由负转正 |
| 利润（20） | TTM 归母同比连续两季改善；TTM 归母同比由负转正；TTM 利润增速快于收入；TTM 扣非同步改善 |
| 利润率（10） | 净利率触底回升；净利率高于过去 4 季均值 |
| 资本与资产（10） | 净资产同比正增长；总资产同比在 0~30% |
| 经营质量（10） | ROE 触底回升；ROA / ROIC 拐点向上 |
| 特殊信号（10） | **投资收益占利润比重下降**；最新业绩预告为正 |

其中"投资收益占利润比重下降"是本模板的关键项：它把"利润增长主要靠投资收益"
这一类伪反转直接扣掉 5 分，并在卡片里说明。
金融股的幅度分也改用 TTM 口径（ΔTTM 收入同比 / ΔTTM 利润同比 / Δ净利率），避免单季投资收益放大。

同比口径：`(本期 − 去年同期) / |去年同期|`，基期为亏损时表示"亏损收窄/扭亏"的改善幅度。

## LEVEL 6 · RPS

```
归一化盈利 = 最近 4 个单季归母中位数 × 4（年化），为负则用 TTM 收入 × 历史单季净利率中位数（恢复性盈利）
Bear  = 归一化盈利 × 0.7 × (行业 PE × 0.8)
Base  = 归一化盈利 × 1.0 × (1 + 0.3×clip(利润同比,0,100%) + 0.2×clip(加速度,0,50%)) × 行业 PE
Bull  = 归一化盈利 × 1.6 × (1 + 同上) × (行业 PE × 1.25)
行业 PE 截断在 [8, 60]；Expected Upside = 目标市值 / 当前市值 − 1
```

分档：>80% Very Large / 50~80% Large / 30~50% Good / 15~30% Moderate / <15% Low，
并分段线性映射为 0~100 分（规格书第 30 节）。已是高估值（PE>72）且 RPS>60 的标的打分 ×0.7。

### 估值硬约束（2026-10 新增，回测验证有效）

```
expensive_entry  = 当前 PE > 行业中位数 × 1.5  或  Base 情景上行空间 < 15%
severe_expensive = 当前 PE > 行业中位数 × 2.0  或  Base 情景上行空间 < 0
```

命中 `expensive_entry` → 等级封顶 B、禁止试探仓；命中 `severe_expensive` → 等级封顶 C。

验证（FRS 前 20% 内部，命中组 − 未命中组的 60 日净收益）：改进前面板 −0.56pp / −0.59pp、
改进后面板 −0.56pp / −0.68pp——**两个面板、两个口径都为负**，说明该约束确实挡住了更差的样本，予以保留。

## Kill Signal（规格书第 44~48 节）

基本面：收入加速度连续下滑且同比转负 / 利润同比 < −30% / 毛利率连续两季恶化且低于 4 季均值 /
存货 >50% 且占收入比上升 / 应收 >50% 且快于收入 / 利润改善但 CFO 为负。

技术面：均线结构破坏（无一条多头且价格低于 MA20 的 93%）/ 相对行业 60 日超额 < −15% /
价格结构分 ≤ 6（关键低点失守）/ **突破失败（近 20 日内突破过 60 日箱体、但收盘已跌回突破位 2% 以下）**。

逻辑面：行业 ODS < 45 / 最新业绩预告增速 < −30%。

1 个 → WARNING，2 个 → REDUCE，≥3 个 → EXIT。

## Big Fish Score 与等级

```
BFS = 0.30·FRS + 0.20·LIS + 0.20·PCS + 0.10·ODS + 0.15·RPS + 0.05·CS   （缺失分项重新归一化）
S ≥85 | A+ ≥80 | A ≥75 | B ≥65 | C ≥55 | <55 Reject
S 级硬门槛：FRS≥75 且 LIS≥70 且 PCS≥70，且 Kill=0、无 Risk Block、无假反转、无价值陷阱
```

四象限：FRS≥70 且 PCS≥65 → BUY ZONE；FRS≥70 且 PCS<65 → WAIT；
FRS<70 且 PCS≥65 → SPECULATION（仅动量，不入主池）；其余 → AVOID。

生命周期：DISCOVERED → FUNDAMENTAL_WATCH(50) → EARLY_REVERSAL(60) → TURNAROUND_CONFIRMED(FRS70+LIS65)
→ PRICE_CONFIRMED(FRS70+PCS65) → ACCELERATION → MATURE → EXIT。

动作门槛：STARTER_POSITION 需 FRS≥70、PCS≥65、BFS≥75 且无重大 Kill；
`收盘/MA20 > 1.15` 时强制降级为 WAIT_PULLBACK（禁止追高）。

## 过滤器（Value Trap / Fake Turnaround）

```
VALUE_TRAP = 低估值(PE<25 或 PB<2) 且 (收入或利润同比为负) 且 (现金流弱或行业 ODS<60)
FAKE_TURNAROUND = 一次性收益占比 > 0.5 或 (归母−扣非)/|归母| > 0.5
                  且【归母在增长、但扣非在跌或显著落后】：np_yoy>0 且 (dedt_np_yoy<0 或 dedt_np_yoy < np_yoy−0.3)
```

> 第二段条件是 2026-10 收窄的结果。回测验证：只按"一次性收益占比高"判定时，
> 命中组 60 日净收益反而比未命中组高 +0.14~0.28pp，说明定义过宽、误杀了正常改善的公司；
> 收窄为"利润改善确实由非经常性损益驱动"后，命中组仍然比未命中组**高 +0.78pp**
> —— 即收窄也没有把这类股票变成差样本。VALUE_TRAP 同样如此（命中组 +0.77~+0.95pp）。
>
> **结论（与规格书第 49/50 节的冲突已如实记录）**：在"基本面反转"这个语境下，
> "便宜 + 当期仍差 + 反转信号强"正是最早的候选，两类过滤器剔除的都是更好的样本。
> 因此系统保留**识别与披露**（规格书要求），但把它们从"硬排除"降级为**封顶 B 级**：
> 不给最高等级，也不踢出候选池。同面板 what-if 显示候选池扩大 22.6%、60 日平均净收益
> 从 +4.63% 变为 +4.66%。
