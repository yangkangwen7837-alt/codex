### 回测核心结论（如实汇报）

1. FRS 分层在**全样本、样本内、样本外三段都保持单调**：60 日净收益 TOP10% +4.63% >
   TOP10-20% +4.03% > MIDDLE +3.27% > BOTTOM +2.38%，多空差 **+2.25pp**
   （结构改进前为 +1.84pp；口径修正前为 +2.09pp）。
2. 样本内 +2.24pp、样本外 +2.25pp——**样本外没有衰减**（修正前的 +1.46pp 是数据缺口造成的）。
   但样本外所有分组都获得 +4% 以上的 60 日收益（普涨行情），绝对收益不可用作证据。
3. BFS 五分位在 20 日与 60 日两个持有期上均单调，多空差 +2.20pp；
   单年滚动窗口里 8/8 年 FRS 多空差为正。
4. **不宣称策略整体有效**：绝对收益被市场 beta 主导，多空差仅 1~2pp，
   且行业成分未做历史回填、ST 时点未回填，仍存在轻微前视。
5. **参数面是平的**：16 种候选池规则变体的配对检验全部不显著，说明"调参"这条路
   在当前样本量下没有信息量；能确定的只有组合宽度对回撤的机械影响。

## 与现有三策略系统的对接口径

现网 "A股高机会密度驱动的三策略交易决策" 仓已使用申万一级行业分类、ODS 硬过滤器、
`Strategy` 统一契约。本 Agent 输出的 JSON 可直接被其读取：

```json
{"strategy": "fundamental_turnaround", "ticker": "601628.SH", "bfs": 76.61,
 "grade": "A", "stage": "TURNAROUND_CONFIRMED", "ods": 72.17, "frs": 82.5,
 "lis": 100.0, "pcs": 40.1, "rps": 100.0, "kill_count": 0,
 "action": "WAIT_TRIGGER", "confidence": 0.9, "reversal_type": "DEMAND_REVERSAL",
 "quadrant": "WAIT"}
```

接入时需注意：两套系统的 ODS 口径**不同**（现网 ODS 六因子为资金密度/盈利效应/趋势/基本面动量/
催化/关注度；本 Agent 的 ODS 按规格书第 6.5 节为景气/资金/预期/周期/估值/政策）。
集成前必须统一到同一套行业 ODS，或在总控层显式区分（规格书第 5 节允许"优先读取已有 Regime/ODS 结果"）。
