## 怎么读（必须一起看）

1. **全样本**策略年化 +23.8%（累计 +415%），同期「全市场等权（含同样成本）」年化 +17.6%、沪深300 累计仅 +36.1%。
2. **超额收益全部来自样本内**：样本内策略年化 +29.6% vs 等权基准 +17.2%（+12.4pp）；**样本外策略 +13.7% vs 等权基准 +18.5%（−4.8pp）**。也就是说，long-only 组合层面样本外没有跑赢市场。
3. **分位多空差 ≠ 组合超额**：FRS/BFS 的多空差在 8/8 年为正（+2.2~2.4pp/60日），但它主要来自**低分组更差**（中位股票同期 −3.8%/年），而 long-only 吃不到空头那一端。
4. **收益分布右偏**：20 日平均 +2.06% 但中位仅 +0.16%；250 日平均 +21.0%、中位 +6.56%。组合收益依赖少数大赢家，这也解释了为什么持仓 5 只时回撤会到 −54%（见 docs/08）。
5. 本口径仍未计入冲击成本、涨跌停无法成交、以及行业/ST 历史回填缺失。
