## 6. 结论（如实汇报）

- 全样本 FRS 多空差：+2.37pp → **+2.25pp**（未改善）
- 样本内 FRS 多空差：+2.35pp → **+2.24pp**（未改善）
- 样本外 FRS 多空差：+2.39pp → **+2.25pp**（未改善）
- 全样本 BFS 多空差：+2.23pp → **+2.20pp**
- 改进前 金融股 FRS 多空差：-0.70pp（top +1.24% / bottom +1.94%，样本 10,395）
- 改进后 金融股 FRS 多空差：-0.26pp（top +1.02% / bottom +1.28%，样本 10,395）

**硬约束有效性（FRS 前 20% 内部，命中组 − 未命中组）**
- 改进前 ·「估值偏高」：-0.37pp → 有效（命中组更差）
- 改进前 ·「估值严重偏高」：-0.51pp → 有效（命中组更差）
- 改进前 ·「低基数」：+0.28pp → 无效（命中组并不更差）
- 改进前 ·「一次性收益」：-0.13pp → 有效（命中组更差）
- 改进前 ·「价值陷阱」：+0.85pp → 无效（命中组并不更差）
- 改进后 ·「估值偏高」：-0.38pp → 有效（命中组更差）
- 改进后 ·「估值严重偏高」：-0.50pp → 有效（命中组更差）
- 改进后 ·「低基数」：+0.25pp → 无效（命中组并不更差）
- 改进后 ·「一次性收益」：+0.59pp → 无效（命中组并不更差）
- 改进后 ·「价值陷阱」：+0.63pp → 无效（命中组并不更差）

> 判读原则：多空差改善才算结构改进有效；若只是绝对收益变化，不算。样本外表现是主要判据，样本内改善但样本外恶化视为过拟合。

## 7. 候选池规则调整的 what-if（在改进后面板上模拟，不需要重跑回测）
